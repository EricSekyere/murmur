# Shortcuts and commands reference

A quick reference to Murmur's activation keys and spoken commands.
Activation is configurable in Settings; the spoken commands are fixed.

## Activation keys

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Start or stop dictation | [[Ctrl+Shift+Space]] | [[Super+Shift+Space]] |
| Double-tap to start or stop | [[Right Ctrl]] twice | [[Ctrl]] twice |
| Toggle command mode | [[Ctrl+Shift+Period]] | [[Ctrl+Shift+Period]] |

Both the hotkey and the double-tap key are configurable in Settings. In
toggle mode (the default), one press or double-tap starts and the next
stops. In hold (push to talk) mode, recording lasts only while you hold
the key. A short silence after you speak can also auto-stop the session.

## Spoken commands

Commands fire only when spoken as the entire phrase; inside a sentence
they are typed as ordinary words.

| Say | Get |
| --- | --- |
| "new line" or "newline" | A single line break |
| "new paragraph" | A blank line |
| "scratch that" or "delete that" | Removes your last phrase |
| "undo that" | Undo |
| "redo that" | Redo |
| "copy that" or "copy selection" | Copy |
| "press tab" or "tab key" | Presses [[Tab]] |
| "press escape" or "escape key" | Presses [[Escape]] |

> **Note:** The two-word "undo that" and "redo that" forms are required
> on purpose; a bare "undo" or "redo" is too easy to misrecognize.

## Literal escape

Prefix a command or snippet with "literally" or "literal" to type its
words instead of running it, for example "literally new line".

## Not voice commands

Paste, cut, and select all are intentionally not voice triggered, because
a single misrecognition could be destructive. Saying them types the words
instead.

## Command mode

Press [[Ctrl+Shift+Period]] to toggle command mode, where phrases act
instead of typing, for example "open the readme file".

> **Warning:** Risky actions always wait for a physical click or keypress
> to confirm, so a misheard phrase cannot act on its own.

## App buttons

On the Dictate view, the mic button starts and stops a session, and Find
pill flashes the floating pill. The floating pill itself doubles as a mic
button you can click from anywhere.
